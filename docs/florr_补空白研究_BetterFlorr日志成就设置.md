## 1. BetterFlorr 插件

### 核心事实

- **它是什么**：**第三方**中文增强插件，**不是** M28 官方出品。官网 https://betterflorr.top/ （Cloudflare 托管，域名约 2025 年中上线；urlscan 记录 https://urlscan.io/result/0197c1ec-b8f7-70be-b956-7a23bb23ab7e/dom/ ）。
- **官方定位（官网首页原文）**：
  - 清新界面（重绘 UI）
  - 简单配置（可视化设置面板）
  - 完全免费
  - **Betterflorr API**：开放 API 供扩展/自定义
  - **Mod 市场**：社区创作的模组
- **安装方式**：B 站有安装教程（搜「curseforge.better florr 插件安装教程」，2025-03-23，BV 号未在搜索结果中完整给出）。具体是桌面客户端还是浏览器注入脚本，**未找到可靠的官方安装文档**，需以官网当前说明为准。
- ⚠️ **封号风险（重要）**：florr.io 官网在检测到不支持的浏览器时直接提示 **"Uninstall any scripts you may have, as they might be interfering with the game"**（来源：https://florr.io 首页，2025-09-19 抓取）。即**官方对第三方脚本/插件是对抗态度**，BetterFlorr、各类油猴脚本（florrkit by zert、修仙版 Cortactin 等）都有封号风险。
- **同类第三方工具**（供参考，均非官方）：
  - **florrkit**（zert，GreasyFork 油猴脚本）：无限缩放、显示碰撞盒、解锁 Unique 花瓣（YouTube 演示 2025-10）。
  - **Florr Auto AFK**（shiny-ladybug.github.io）：另一款挂机工具，自称 90% 识别准确率、窗口钩子后台检测、AFK 验证码识别。
  - **florr-helper**（npm 包，koishi 聊天机器人插件）：非游戏内外挂。

### 它能给挂机插件提供什么数据？

- 官网宣传有 **Betterflorr API**，但**公开 API 文档/数据格式未在搜索中找到**。若该 API 能在浏览器内直接读出怪物血量/坐标/掉落事件，理论上可以替代你现在的屏幕取色——**但需先确认 API 是否暴露游戏内实体状态，以及它是否要求注入 BetterFlorr 客户端**。
- **现实结论**：你现有的 `florr-auto-pathing` 是纯屏幕取色（window_ctrl + 1px 色表），不依赖任何第三方插件。这其实是**最安全的路线**——再叠 BetterFlorr 等于是把号借给一个会被官方检测的注入层。

### 对挂机插件的影响与建议

1. **不要在挂机环境里同时装 BetterFlorr/油猴脚本**：官方首页明确要求卸载脚本，两个注入层叠加会同时触发反作弊，封号概率相乘。
2. **BetterFlorr API 仅作调研方向**：若想拿到怪物真实血量/坐标（替代脆弱的颜色识别），可以去 betterflorr.top 看它的 API 文档；但在确认官方态度前，**不要把自动号挂在它上面跑**。
3. **你现有的屏幕取色方案反而合规**：纯读像素 + PostMessage 键盘，不注入游戏进程，风险低于任何油猴脚本。继续保持。
4. **AFK 验证码**：Florr Auto AFK 提到游戏有 AFK 检查（anti-AFK check）。你的 README 已做随机微转向/微停顿，方向正确；若遇到弹窗验证码，目前是人工处理——这是外挂难以绕过、官方专门留的口子。

## 2. 游戏日志 / 数据怎么看

### 游戏内有没有日志？

- **没有战斗日志/掉落日志文件**。florr.io 是实时 io 游戏，所有状态在内存里，不落盘。
- 游戏内可见的信息：
  - **伤害数字**：2022-12-26 加入，设置里可开关，**默认开**（changelog）。
  - **聊天栏广播**：全服通知「An Ultra/Super X has spawned somewhere!」；Super 生物生成时通知全服 **75 级以上**玩家（中文维基生物表）。
  - **Mob Gallery（怪物图鉴）**：记录你击杀过的每只怪（见第 3 节）。
- **第三方掉落统计**：游戏本身不记录「我掉了几张 U」这类统计，只能自己记或靠第三方网站。

### 浏览器开发者工具能抓到什么？

- florr.io 是 WebSocket 实时游戏。按 **F12 → Network → 筛选 WS**，能看到一条到游戏服务器的 WebSocket 长连接；Messages 里是**二进制帧**（ArrayBuffer），不是可读 JSON，需要自己逆序列化。
- 这意味着：**理论上可以从 WebSocket 帧里直接拿到怪物坐标/血量/掉落事件**，比屏幕取色精确得多。但协议未公开、会随版本变，且**读包本身属于抓游戏流量，有封号争议**。
- 你现有方案走的是屏幕像素，不碰网络层，避开了这个雷区。

### 第三方实时追踪站（推荐，安全）

**FlorrMobNotify（mobs.ashish.top / ashish.top）**——纯网页、无需装插件：

| 功能 | 说明 |
|---|---|
| 实时事件流 | 怪物生成/被击杀/裂隙事件，WebSocket 推送，无轮询，<100ms 延迟 |
| 浏览器通知 | Super/Unique/Eternal 生成时系统级弹窗（标签页后台也响），可加声音 |
| 区服过滤 | 只提醒你所在区域 |
| 裂隙（Rift）追踪 | 实时状态 + 历史赢家记录 |
| 商店监控 | 检测每日商店轮换 |
| Unique 锻造追踪 | 当前正在进行的 Unique 锻造位置面板 |
| 每日统计 | 当天各稀有度生成/击杀数 |
| 实时怪物网格 | 按区服列出当前存活怪物 |

- 数据来源：它自己的服务器持续监听 florr.io 游戏服事件，再推给浏览器；客户端只用浏览器原生通知（来源：https://mobs.ashish.top/about/ 、https://ashish.top/how-it-works/ ，2026-06）。
- **FlorrMapBrowser（maps.ashish.top）**：直接从 florr.io 服务器拉实时地图数据，可缩放平移，显示难度区、怪物出生点、检查点等级要求（2026-05）。

### 对挂机插件的影响与建议

1. **把 mobs.ashish.top 开在另一个标签页当「雷达」**：它不注入游戏、不封号。当它推送「Super X 在你所在区生成」时，插件可以从你 Python 侧读这个网页/通知，作为「要不要停止巡逻赶过去」的信号源——比纯巡逻效率高。
2. **maps.ashish.top 的地图数据可用来校验你的 .tmj**：你已经手工转了 10 张地图（`*.tmj`），可以对照 FlorrMapBrowser 修正出生点/捷径坐标。
3. **不要自己去逆 WebSocket 包**：收益（精确血量）不值得封号风险，现有颜色识别已够。
4. **伤害数字保持开启**：它是你 `combat.py` 判断「打中没/秒杀没」的视觉辅助依据之一，别在设置里关。

## 3. 成就 / 图鉴系统

### 成就（Achievements）

- **加入时间**：2024-05-08（changelog：「Added achievements. They provide TP which will replace the ones lost from the levels you lost.」）。
- **核心作用**：**给 TP**。2024-05-08 等级需求翻倍、玩家等级减半，被砍掉的 TP 由成就补回。
- **存档机制**：2024-05-11 改过一次存档方式，部分成就被重置；但**从此一旦完成就永久保留，即使以后改需求也不回滚**。
- **已知成就名**（散见 YouTube 成就系列、洛谷教学）：
  - **Biologist**：击杀全部种类生物（Hel 版变体叫 "Bad in Every Way"）。
  - **Collector**：收集类成就。
  - **Conqueror**：获得第一个 Unusual（namu 记载）。
  - **PATIENT DEALER**：99→100% 进度类。
  - **Touched**：触摸开发者（隐藏成就）。
  - 洛谷教学里还提到：同归于尽（用 Iris 毒杀别人）、自我牺牲（双人配合训练假人）、赛车手（Bubble+Powder+Rubber）、连环杀手（沙漠→金字塔缝隙刷低级怪）、纹丝不动（开键盘移动站定）。
- **每个成就具体给多少 TP**：**未找到可靠数据**（无完整成就表）。

### 图鉴 / Mob Gallery

- **加入时间**：2022-09-12（changelog：「Added extra stats in mob gallery」）。
- **作用**：记录你击杀过的每只怪及其属性（血/伤害/经验/掉落），在游戏内查看。
- **关键规则**（中文维基生物表，2026-04）：
  - Super 生物生成时全服通知 **75 级以上**玩家。
  - **75 级以前杀 Super 怪只掉 Ultra 级材料，但图鉴仍会记录**（只显示 Ultra 掉落和经验）。
  - **身上没带够 4 张 Ultra 花瓣前，杀 Super 也只给 Ultra 掉落**（防新手抢 Super）。
- **图鉴本身没有直接给 TP/奖励**，主要作用是信息查询 + 配合成就 Biologist。

### 花瓣收藏 / 库存

- 花瓣分**装备栏（花瓣窗）**和**物品栏（背包）**：打到的花瓣先进花瓣窗，满了进背包（namu 脚注）。
- 设置里有 **「Equip drops」开关**：关掉后，掉落的花瓣直接进背包，跳过装备栏。
- 花瓣可在 NPC（Trader/Oracle/Assembler/Titan）和主菜单 Premium Shop 之间流转（见前序报告）。

### 对挂机插件的影响与建议

1. **75 级 / 4 张 U 的 Super 掉落门槛**：插件如果提示玩家「去抢 Super」，要先检查等级和 U 花瓣数——不满足条件去了也是白跑，只给 U 掉落。
2. **Biologist 成就 = 挂机顺带完成**：你的巡逻路线覆盖的怪种越全，越能自动解锁图鉴。可以在 README 里加一句「挂机顺便点亮 Mob Gallery」。
3. **成就给 TP 是长期收益**：洗点免费，所以不必刻意刷成就，挂机过程自然拿到即可。插件无需为此做专门逻辑。

## 4. 花瓣掉落稀有度概率细节

### 掉落资格（伤害贡献门槛）

- **PvE 掉落按伤害贡献分配**，各来源数字略有出入：
  - changelog 2023-02-14：Ultra+ 怪掉血门槛从 5% 降到 **1%**，同分掉落人数上限从 4 提到 **15**。
  - ashish.top（2026-04-10）：普通怪需 ≥15% 伤害且前 4 名；Super+ 需 ≥1% 伤害且前 25 名。
  - 你插件 README 采用「U 级以下 4 人分、>1% 有资格」。
  - ⚠️ **15% vs 1%（普通怪门槛）、25 vs 15（同分人数）两处不一致**，以官方 changelog 的 1% / 15 人为准更稳；插件 `leech` 打 2.5 秒混伤害的策略在两种说法下都成立（1% 门槛极低）。
- **掉落按玩家独立随机**：2023-02-27 起，不再所有人掉同一份，每个参与者独立 roll（changelog）。

### 单个怪掉什么、各稀有度概率

- **不是「怪稀有度决定花瓣稀有度」一句话能概括的**：同一只怪会掉多种花瓣，每种花瓣再有自己的稀有度 roll。举例（YouTube Super Shell 实录，2023-09）：
  - Super Shell 掉 Magnet：Legendary 77.3% / Mythic 21.9% / Ultra 0.8%
  - Super Shell 掉 Shell：Legendary 2.1% / Mythic 86.2% / Ultra 11.7%
- 即：**每只怪、每种掉落花瓣都有一张独立的稀有度分布表**，全部列在中文维基各花瓣/生物页（如蜂蜡页有 L/M/U/S/Uni 各 10.7%/98%/3.3%… 这种表）。**没有统一的「打怪掉稀有度百分比表」**，要查具体怪得翻对应花瓣页。
- **高一级怪血量 ≈ ×3.6~46，经验只 ×4~9**（你 README 已引用），所以「只打能秒的同级」是对的。

### Magic Orb / 幸运值（Luck）

- **Luck 天赋数值**（namu.wiki，2026-03）：

| 档位 | Luck 增加 | TP |
|---|---|---|
| Unusual | 0.1 → 0.25 | 3 |
| Rare | 0.25 → 0.45 | 4 |
| Epic | 0.45 → 0.7 | 5 |
| Legendary | 0.7 → 1 | 6 |
| Mythic | 1 → 1.35 | 7 |
| Ultra | 1.35 → 1.75 | 8 |

- **Luck 效果**：
  - 幸运草（Clover）花瓣：每点幸运 +4% Dice 暴击率；传奇幸运草自带 1% 额外掉落概率。
  - **2025-10-14 起 Luck 再次影响刷怪**：提高该区域生成怪物的稀有度（changelog：「Luck now affects mob spawns again」）。
- **Magic 花瓣**：设置文件 attributes.txt 里有 `AllowsFindingMagicPetals`（允许发现魔法花瓣）属性——魔法花瓣是特殊稀有掉落，具体机制**未找到可靠数据**。

### 对挂机插件的影响与建议

1. **插件 `kill_rank` 逻辑正确**：打能秒的同级 = 100% 伤害 = 必拿掉落；越级打高一级血 ×46 不划算。保持。
2. **`leech` 蹭掉落 1% 门槛足够**：1% 伤害贡献极低，2.5 秒混伤策略有效，且同分人数 15 人够多，蹭到概率不低。
3. **Luck 天赋值得挂机党点**：它直接提高刷怪稀有度 = 同样巡逻时间掉更好的卡。建议在加点建议里把 Luck 加到「富余 TP」优先级里。
4. **别追着每只怪查掉落表**：插件按颜色识别稀有度即可，具体花瓣种类不影响挂机决策。

## 5. 游戏内设置项

### 已知设置项（从 changelog / namu / 中文维基整理）

| 设置 | 作用 | 对挂机插件的影响 |
|---|---|---|
| **伤害数字** | 开关飘字，默认开（2022-12-26） | **保持开**：辅助判断命中/秒杀 |
| **聊天栏** | 在设置里开启才显示（中文维基聊天栏页） | 广播里有 Ultra/Super 生成提示；挂机时建议开着以便人工看通知 |
| **花瓣转速** | 2024-05-30 起可精确控制，最慢 30% 最高速 | 影响 DPS，挂机前手动调好 |
| **Equip drops（拾取即装备）** | 关掉则掉落直接进背包（namu 脚注） | 挂机党建议**关掉**，避免自动装备打乱你配好的 loadout |
| **Loadout 自动保存** | 2025-01-16 加：切 loadout 时自动存；关则按 O 手动存 | 别让插件切槽时意外覆盖你的配装 |
| **Auto-join squads** | 设置里的小队自动加入开关（namu） | 挂机时建议关，避免被拉进陌生队 |
| **屏幕分辨率/缩放** | 自适应 4K/1080p | 你插件已自动标定，无需手调 |
| **画质/粒子** | 未在搜索中找到完整列表 → 未找到可靠数据 | 建议手动调低以提 FPS、减少画面干扰颜色识别 |

### 对挂机插件的影响与建议

1. **启动引导里加一句「设置检查清单」**：Equip drops 关、Auto-join squad 关、伤害数字开、聊天开。这四项直接影响挂机稳定性。
2. **低画质提 FPS**：你的帧差检测躲弹依赖帧率，画质越低、粒子越少，颜色识别越干净。建议 README 补一句「游戏画质拉最低」。
3. **不要让插件去改这些设置**：设置是账号级的，手动配一次即可。

## 6. 其他值得补的机制

### 小队（Squad）

- 命令（中文维基聊天栏页，2024-02）：
  - `/squad-create`（默认私有）、`/squad-join <代码>`、`/squad-leave`、`/squad-find-public`、`/squad-public`、`/squad-private`、`/squad-share`、`/squad-invite`。
  - 聊天：Enter 说话，**Tab** 在 [Local] 和 [Squad] 间切；/local、/squad 也可切。
- 规则：最多约 4 个相近等级玩家；**小队共享掉落，但最小伤害门槛随人数增加**（namu）；能在地图上看到队友位置。
- **对挂机**：单挂最稳；组队蹭 Super 时共享掉落但门槛上涨，插件单挂即可。

### 公会（Guild）

- 2023-12-29 加入基础功能，**目前只能聊天命令使用**（changelog）。无明确挂机收益。

### PvP

- 2023-03-17 回归，入口在 Centralia 东侧。
- 三个难度竞技场：Common–Epic / Legendary–Mythic / Ultra–Super，按你装备最高稀有度花瓣自动分场；**场内不能换 loadout**。
- PvP 里 Magnet 不增加拾取范围（2022-09-13）。
- **对挂机**：挂机号别进 PvP，Corruption 花瓣会招来仇杀。

### 每日挑战 / Stars

- 2024-04-03 起：每天要杀指定怪拿 Stars；Stars 不再被动产出（2024-04-01 起广告对全员关闭但仍发 Stars）。
- Stars 数量按怪稀有度（namu）：Legendary 10 / Mythic 20 / Ultra 40 / Super 160；**每 6 小时轮换目标怪**。
- Stars 在主菜单商店买花瓣。

### Boss / 裂隙（Rift）

- Boss 血条在屏幕上方；击杀按「伤害占比/排名 ×100」计分（中文维基 Boss 生物页）。
- Rift（裂隙）：2025-12-21 花园裂隙把花带回「更简单的时代」；ashish.top 实时追踪裂隙状态和赢家。
- 每周/节日活动：M28 不定期开圣诞活动（2024-12-25 曾临时送普通腐化）、map 轮换活动等。

## 末尾总结：对挂机插件的影响与建议（汇总）

1. **安全优先级最高**：别叠 BetterFlorr/油猴脚本，官方明确要求卸载脚本；你现有纯屏幕取色 + PostMessage 键盘是最安全路线，继续保持。
2. **雷达外挂（安全）**：把 mobs.ashish.top 开在旁边当 Super/Unique/Rift 雷达，可作为插件「停止巡逻赶场」的外部信号源；maps.ashish.top 可校验你的 .tmj 地图坐标。
3. **启动设置引导**：插件首次运行时弹窗提示玩家手动确认——Equip drops 关、Auto-join squad 关、伤害数字开、画质拉最低。
4. **Super 门槛提醒**：75 级以下 / 身上不足 4 张 U 时，杀 Super 只给 U 掉落，插件别在这种状态下引导玩家去抢 Super。
5. **Luck 天赋值得点**：2025-10 起 Luck 重新影响刷怪稀有度，同样巡逻时间掉更好的卡，加点建议里补入。
6. **别碰网络层逆包**：WebSocket 是二进制帧，逆协议收益不值得封号；颜色识别已够用。

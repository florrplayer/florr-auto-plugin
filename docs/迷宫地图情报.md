# 官方迷宫地图情报（florr_clone src/maze.ts 源码级）

来源: reference-florr-tools/florr_clone/src/maze.ts（克隆版复刻官方 Maze 模式）
状态: 2026-10 已破解结构，插件暂不接入（玩家在常规图挂机，迷宫在超远坐标）

## 地图位置
- 原点 MAZE_ORIGIN = (200000, 200000) 世界坐标
- 在常规 60000x60000 地图 和 PVP 竞技场 (150000,150000) 之外，独立坐标空间

## 轮换机制
- 每天轮换 biome: garden / desert / ocean（day % 3）
- 服务器和每个客户端由单一 `mazeInfo { day }` 消息构建**字节级相同**的迷宫
- 不走网络传墙数据——客户端本地生成

## 迷宫结构
- 模板格（N×N 字符数组）→ 每格展开 2x2 网格
- 网格单元 = 1000 世界单位
- 模板尺寸 8~64 → 网格 128 → 世界跨度 76800
- 网格值（与 rrolf rr_maze_grid 相同语义）:
  - 0 = 实心墙/虚空
  - 1 = 可走地板
  - 4~7 = 凸圆角地板格（bit0=上, bit1=左）
  - 12~15 = 凹圆角墙格（bit3 置位, bit0=上, bit1=左）
  - 同一值同时驱动碰撞和渲染：看到的就是碰到的

## 难度分区
- 按走廊深度（BFS 距离入口）分 6 档: common/uncommon/rare/epic/legendary/mythic
- Ultra 怪**只**在最深 mythic 房作为 Boss 生成
- 迷宫内最高可用花瓣稀有度 = mythic（Ultra 及以上被禁用）

## 对插件的意义
- 若以后要支持迷宫: 客户端可本地生成墙碰撞图（无网络依赖），
  插件读 `mazeInfo.day` 即可构建路线
- Ultra+ 禁用 → 迷宫内只刷 mythic 及以下，掉落上限 Legendary/Mythic
- 迷宫入口/respawn 点=spawn 房中心，Boss 房坐标由 mazeInfo 广播
